# Surfboard

Одностраничный лендинг магазина профессиональных серфбордов **Surfboard**.

Проект выполнен на HTML, SCSS и JavaScript с использованием сторонних библиотек и API для реализации интерактивных элементов: слайдера товаров, формы заказа, видеоплеера и карты.

**Демо:** https://rudanastasia.github.io/surfboard/

## Возможности

* адаптивная верстка для разных размеров экрана;
* навигация по секциям одностраничного сайта (боковое липкое меню);
* мобильное hamburger-меню;
* слайдер серфбордов;
* просмотр характеристик товара;
* интерактивный блок команды;
* форма заказа;
* маска для ввода номера телефона;
* отправка формы через Formspree;
* YouTube-видеоплеер;
* интерактивная карта с адресом магазина;
* SVG-иконки и спрайт;
* ESLint и Prettier для проверки и форматирования кода.

## Основные разделы

Главная страница `index.html` содержит следующие блоки:

* **Hero** — презентация магазина и призыв к заказу;
* **Почему Surfboard?** — преимущества серфбордов;
* **Серфборды** — каталог слайдов с товарами и характеристиками;
* **Команда** — информация о сотрудниках;
* **Меню** — дополнительные элементы каталога;
* **Отзывы** — отзывы клиентов;
* **Как мы работаем** — видеопрезентация;
* **Контакты** — форма заказа и карта.

## Технологии

### Основные

* **HTML5** — структура страницы;
* **SCSS** — организация и стилизация интерфейса;
* **CSS** — скомпилированные стили;
* **JavaScript** — интерактивность;
* **jQuery 3.4** — работа с DOM и интерактивными компонентами.

### Библиотеки и API

* **bxSlider** — слайдер карточек серфбордов;
* **IMask.js** — маска телефонного номера в форме заказа;
* **YouTube IFrame API** — встроенный видеоплеер;
* **Yandex Maps API v3** — интерактивная карта;
* **Formspree** — обработка заявок без собственного backend-сервера.

### Инструменты разработки

* **ESLint** — статический анализ JavaScript;
* **Prettier** — форматирование кода;
* **Prepros** — компиляция SCSS и обработка CSS.

## JavaScript

Основная логика проекта находится в:

```text
js/script.js
```

JavaScript отвечает за интерактивные элементы страницы, в том числе:

* мобильное меню;
* липкое меню - навигация по секциям страницы;
* слайдер серфбордов;
* открытие характеристик товаров;
* интерактивный блок команды;
* форму заказа;
* работу маски телефона;
* YouTube-плеер;
* карту Yandex Maps.

Для сторонних глобальных объектов в ESLint настроены соответствующие browser globals:

```text

jQuery
IMask

```

## Слайдер серфбордов

В каталоге используется **bxSlider**.

Слайдер позволяет переключаться между моделями серфбордов и просматривать:

* название;
* описание;
* длину;
* ширину;
* стоимость;
* дополнительные характеристики.

В карточках товаров доступна отдельная панель с параметрами:

* длина доски;
* ширина;
* толщина;
* срок службы;
* вес.

## Форма заказа

На странице расположена форма для оформления заявки.

Для номера телефона используется **IMask.js**, благодаря чему пользователь вводит номер в заданном формате.

Отправка данных осуществляется через **Formspree**, поэтому отдельный backend для обработки формы в проекте не требуется.

## YouTube

В разделе «Как мы работаем» используется **YouTube IFrame API**.

Из-за использования внешнего API проект рекомендуется запускать через локальный HTTP-сервер, а не открывать `index.html` напрямую через `file://`.

## Yandex Maps

В разделе контактов используется **Yandex Maps API v3** для отображения интерактивной карты.

Для корректной работы карты необходимо, чтобы страница была запущена через HTTP-сервер и внешние ресурсы были доступны браузеру.

## Стили

Исходные стили находятся в SCSS-файлах каталога `css/`.

Процесс обработки настроен через `prepros.config`:

```text
SCSS
  ↓
Dart Sass
  ↓
Autoprefixer
  ↓
css/main.css
```

Prepros автоматически компилирует SCSS в CSS.

Скомпилированный файл:

```text
css/main.css
```

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/rudanastasia/surfboard.git
cd surfboard
```

Установите зависимости:

```bash
npm install
```

## Локальный запуск

Проект является статическим и не требует backend-сервера или отдельной сборки JavaScript.

При этом **не рекомендуется открывать `index.html` двойным кликом**.

Для запуска можно использовать, например, Live Server в VS Code.

Также подойдёт любой локальный HTTP-сервер:

```bash
npx serve .
```

После запуска откройте адрес, который выведет сервер, и перейдите на:

```text
/index.html
```

HTTP-сервер необходим для корректной работы внешних API, в частности YouTube и Yandex Maps.

## Проверка кода

Проверить JavaScript с помощью ESLint:

```bash
npm run lint
```

```bash
npm run lint:fix
```

Проверить форматирование:

```bash
npm run format:check
```

Отформатировать проект:

```bash
npm run format
```

## Сборка

Отдельного `npm run build` в проекте нет.

SCSS компилируется средствами **Prepros**, конфигурация находится в:

```text
prepros.config
```

Поэтому для разработки достаточно запустить локальный HTTP-сервер, а при изменении SCSS использовать Prepros для получения актуального `css/main.css`.
